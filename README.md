# Meu Financeiro

Aplicação web pessoal para registrar receitas, despesas, parcelamentos e investimentos.

Os dados locais são armazenados no navegador e sincronizados por usuário com o Supabase.

## Configuração do Supabase

Antes de usar a sincronização, abra o **SQL Editor** do projeto Supabase e execute o arquivo `supabase-schema.sql`.

O projeto está configurado para confirmar o e-mail antes do primeiro acesso. Após criar a conta, confirme o link recebido no e-mail e então entre na plataforma.
